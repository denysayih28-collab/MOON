# M.O.O.N.

M.O.O.N. is an interactive web-based prototype for monitoring astronauts' health and well-being.

## Objectives

- Visualize health metrics and physiological indicators.
- Explore anatomical regions through an interactive 3D model.
- View charts and historical measurement data.
- Understand alerts triggered by explicitly defined rules.
- Clearly distinguish between simulated data, manually entered measurements, and data obtained from public sources.

## Disclaimer

M.O.O.N. is a demonstration prototype and is not intended for medical diagnosis or clinical decision-making. Simulated data must be clearly identified as such.

## Planned Technology Stack

- Frontend: React and TypeScript
- 3D Visualization: Three.js and React Three Fiber
- Data Visualization: Recharts
- Backend: Python and FastAPI
- Data Storage: SQLite
